Iconographie (qc-icon)

Le composant qc-icon permet d'afficher une icône avec la bonne couleur quel que soit le thème.

Documentation technique

Attributs

Nom Valeur attendue Valeur par défaut Description
type (icon) Texte "" Nom de l'icône à afficher (Material Symbols ou alias legacy).
variant outlined, filled outlined Variante de l'icône Material Symbols.
label Texte "" Texte alternatif pour l'accessibilité. Sert de libellé pour les lecteurs d'écran. Si absent, l'icône sera masquée au lecteur d'écran (via l'attribut aria-hidden).
rotate Nombre na Rotation de l'image en degrés dans le sens horaire.
size xs, sm, md, nm, lg ou xl md Taille de l'icône.
color Toute valeur correspondant à un jeton de couleur une fois précédée de --qc-color-. Par exemple, "text-primary" donne la couleur de --qc-color-text-primary text-primary Couleur de l'icône.
width Toute valeur acceptée par la directive css width auto Largeur personnalisée de l'icône.
height Toute valeur acceptée par la directive css height auto Hauteur personnalisée de l'icône.
src Toute valeur acceptée par la fonction css url() na Chemin pour afficher une icône personnalisée.
use-material Booléen (présence de l'attribut) false Force l'utilisation du nom comme icône Material Symbols, sans passer par le mapping legacy. Utile lorsqu'un nom Material entre en conflit avec un alias legacy (ex. : note).
codepoint Code hexadécimal Unicode (ex. : E873) — Affiche une icône Material Symbols par son codepoint Unicode, sans qu'elle soit incluse dans le subset de la trousse. Nécessite l'inclusion dynamique de la font via un <link> Google Fonts (voir le guide de migration).
