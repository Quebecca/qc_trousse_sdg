Utilisation sans le composant Web

Pour appliquer uniquement le rendu visuel d’un tableau de données, ajoutez la classe qc-table directement sur la balise <table>. Vous pouvez également la combiner avec les classes qc-table--grey-header ou qc-table--simplified pour utiliser l’une des variantes visuelles du tableau.

Défilement horizontal

Le composant Web <qc-table> prend en charge le défilement horizontal lorsque le tableau ou la liste structurée dépasse la largeur disponible. Ce comportement s’applique aux tableaux de données, quelle que soit la taille de l’écran. Sur mobile, les listes structurées sont plutôt présentées sous forme de cartes.

Sans le composant Web, la gestion du défilement horizontal doit être prévue par l’implémenteur. Placez le <table> dans un conteneur portant la classe qc-table-container pour reproduire le même comportement, comme dans l’exemple précédent.

Liste structurée (qc-table)

Une liste structurée permet de présenter une information principale accompagnée d’un ensemble de détails associés. Elle repose sur la structure d’un tableau HTML, mais adapte sa présentation sur le mobile afin de faciliter la lecture des données.

Le tableau simplifié et la liste structurée peuvent avoir une apparence similaire sur écran large, notamment avec des en-têtes sur fond blanc, mais ils répondent à des besoins différents.

structured-list Présence de l'attribut Absent Si présent, le tableau est affiché en liste structurée et, sur le mobile, sous forme de cartes. En son absence, le tableau est affiché normalement.

Accessibilité

NB : Le titre de la liste structurée, tout comme celui du tableau standard, doit être placé dans l’élément <caption>.

Pour la fusion des cellules des données le composant <qc-table> gère la présentation des données, mais pas l'accessibilité du contenu : il revient à l'implémenteur de fournir un tableau valide et accessible.
