Notes (qc-note-ref / qc-note-list)

Les notes apportent un complément d'information sans alourdir le texte. Chaque note est représentée dans le contenu par un numéro qui est relié à la description en bas de page.

Redimensionnez votre fenêtre à moins de 768px pour voir le comportement mobile. L'activation (clic ou clavier) ouvrira une feuille au lieu de scroller vers la définition ci-dessous.

Attributs — qc-note-ref

Attribut Type Défaut Description
note-id String — Identifiant de la note. Plusieurs appels avec le même note-id pointent vers la même définition (note partagée).
definition String (HTML) "" Texte de la définition. Requis sur au moins un appel par note-id. Supporte le HTML (gras, liens, etc.).
scope String "page" Scope de numérotation. Les notes d'un même scope partagent une numérotation séquentielle indépendante. Utiliser un scope distinct pour les notes de données (tableau/graphique).
term String "" Le terme à définir. Si présent, le terme et le numéro sont soulignés ensemble en pointillé. Si absent, seul l'exposant est affiché.

Attributs — qc-note-list

Attribut Type Défaut Description
scope String "page" Scope dont les définitions seront affichées. Doit correspondre au scope des qc-note-ref associés.
display String — Mode d'affichage. Si absent, les définitions s'affichent en bas de page (comportement par défaut). Si "sheet", le clic sur un appel de note ouvre une feuille.
title String "" Titre affiché au-dessus de la liste des définitions (ex : « Notes et références »). Si absent, aucun titre n'est affiché.
