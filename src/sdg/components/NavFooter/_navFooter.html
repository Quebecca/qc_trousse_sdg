Documentation technique

Attributs
Nom Valeur attendue Valeur par défaut Description
title-text Texte Aucune Obligatoire. Titre du site ou du service. Absent : aucun titre et un avertissement dans la console.
title-url Adresse / Lien du titre (page d’accueil).
title-tag h2 à h6 h2 Niveau du titre. Valeur invalide : h2.
description Texte Chaîne vide Courte description affichée sous le titre.

Zones d’ajout de contenu HTML

Ci-dessous, les zones d’ajout de contenu HTML (balise <slot>) délimitées en pointillé. La zone links reçoit une liste <ul> de liens de contact ; la zone columns reçoit les colonnes (classe qc-nav-footer-column), directement ou dans un <nav> intermédiaire. Le composant ne rend ni <nav> ni <footer> : l’intégrateur les écrit.

slot="links"
slot="columns"

Classes CSS

Classes du pied de page de navigation
Classe Description
qc-nav-footer-column À ajouter sur chaque élément de la zone columns qui doit s’afficher comme une colonne (<div>, <section> ou <nav>). La colonne occupe le tiers de la largeur à partir de 768 px (bureau et tablette), et toute la largeur en dessous : l’équivalent de qc-col-sm-4 dans la grille de 12 colonnes. Un élément sans la classe n’est pas une colonne.
qc-social-<réseau> À ajouter sur le <a> d’un lien vers un réseau social pour afficher l’icône du réseau : blogger, bluesky, facebook, instagram, linkedin, pinterest, rss, soundcloud, tiktok, x, youtube. Voir l’exemple « Liens vers les médias sociaux ».

Accessibilité

  • Liens natifs seulement ; ordre du focus identique à l’ordre visuel.
  • Chaque <nav> écrit par l’intégrateur a un nom unique, différent de celui des liens du pied de page du PIV.

Cas non pris en charge

  • Plus de trois colonnes (la quatrième passe à la rangée suivante).
  • Plusieurs pieds de page de navigation dans une page.
  • Largeur de contenu autre que celle de la grille.
  • Lien de média social sans texte (icône seule).
