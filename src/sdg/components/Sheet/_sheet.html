Feuille (qc-sheet)

La feuille est utilisée pour afficher du contenu secondaire sans interrompre la tâche principale de l'utilisateur. Elle fonctionne en mode modal : le contenu en arrière-plan est grisé et désactivé.

Attributs

Attribut Type Défaut Description
title String "" Titre affiché en gras en haut du contenu de la feuille. Utilisé aussi comme nom accessible du dialog (aria-labelledby). Si aucun titre n'est fourni, le dialog reçoit un aria-label générique (« Feuille » / « Sheet »).
description String (HTML en ligne) "" Contenu de la feuille. Le composant l'entoure lui-même d'un paragraphe : ne pas inclure de balise <p> dans la valeur. Les balises en ligne (liens, gras, etc.) sont supportées. Pour du contenu de bloc (plusieurs paragraphes, listes), utiliser plutôt le contenu par défaut (voir « Utilisation en Svelte » ci-dessous).

Utilisation en Svelte

En plus de l'attribut description, la feuille accepte du contenu par défaut (children) lorsqu'elle est utilisée directement comme composant Svelte. Le contenu fourni remplace alors description, ce qui permet d'afficher du contenu de bloc riche ou des composants imbriqués. C'est le mécanisme utilisé par l'infobulle (qc-tooltip) pour afficher son contenu en feuille.
