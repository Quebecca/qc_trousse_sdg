Pastilles

La pastille est utilisée pour visualiser des états ou fournir une information complémentaire. Elle est constituée des éléments suivants :

  • une zone de couleur qui varie en fonction de l'attribut sélectionné
  • un libellé - via l'attribut aria-label
  • une icône (optionnel)

Ajout obligatoire du libellé

Comme la couleur seule ne transmet pas l'information aux utilisateurs de technologies d'assistance ou daltoniens, ajoutez l'attribut aria-label sur la pastille (.qc-lozenge) pour indiquer la nature du statut au lecteur d'écran (ex. : « Information », « Succès », « Erreur », « Avertissement », « Complément »). Voir l'exemple de pastille générale.

Icône personnalisée

L'édimestre peut placer une icône de son choix avec <qc-icon> et encapsuler le libellé dans qc-lozenge-label. La règle d'icône automatique (qc-lozenge-icon) est alors désactivée : l'icône choisie l'emporte. Le wrapper isole le libellé pour que l'ellipse morde sur le texte sans tronquer l'icône.

Combinaison de pastilles

La combinaison de plusieurs pastilles est permise dans les contextes de contenu courant (paragraphes, tableaux de données, contenu d'accordéon, de feuille, dialogue modal, etc.). Un espacement de 8 px est appliqué horizontalement et verticalement entre les pastilles adjacentes.

Classes de pastilles
Classe Élément Description
qc‑lozenge <span> Classe de base obligatoire. Définit la forme pill, les dimensions (min 32 px, max 288 px), la typographie et l'ellipse automatique. Voir l'exemple de pastille générale.
qc‑general .qc-lozenge Pastille générale (bleue). Statut par défaut. Voir l'exemple de pastille générale.
qc‑success .qc-lozenge Pastille de succès (verte). Voir l'exemple de pastille de succès.
qc‑error .qc-lozenge Pastille d'erreur (rouge). Voir l'exemple de pastille d'erreur.
qc‑warning .qc-lozenge Pastille d'avertissement (jaune). Voir l'exemple de pastille d'avertissement.
qc‑complementary .qc-lozenge Pastille complémentaire (grise). Voir l'exemple de pastille complémentaire.
qc‑lozenge‑icon .qc-lozenge Modificateur optionnel qui affiche l'icône canonique du type en pseudo-élément CSS (info, check_circle, cancel, warning, emoji_objects) — sans composant web, donc sans décalage de mise en page. Ignoré si un <qc-icon> est présent dans la pastille. Voir l'exemple de pastille générale.
qc‑lozenge‑label <span> enfant Encapsule le libellé lorsqu'un <qc-icon> personnalisé est présent, pour appliquer l'ellipse au texte sans tronquer l'icône. Voir l'exemple d'icône personnalisée.
qc‑lozenge‑group <div> conteneur Conteneur pour pastilles combinées. Gère l'espacement horizontal et vertical. Voir l'exemple de combinaison de pastilles.
