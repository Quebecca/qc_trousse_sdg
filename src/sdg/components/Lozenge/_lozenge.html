Pastilles

La pastille est utilisée pour visualiser des états ou fournir une information complémentaire. Elle est constituée des éléments suivants :

  • une zone de couleur qui varie en fonction de l'attribut sélectionné
  • un libellé
  • une icône (optionnel)

Combinaison de pastilles

La combinaison de plusieurs pastilles est permise dans les contextes de contenu courant (paragraphes, tableaux de données, contenu d'accordéon, de feuille, dialogue modal, etc.). Un espacement de 8 px est appliqué horizontalement et verticalement entre les pastilles adjacentes.

Classes CSS

Classes de pastilles
Classe Élément Description
qc‑lozenge <span> Classe de base obligatoire. Définit la forme pill, les dimensions (min 32 px, max 288 px), la typographie et l'ellipse automatique.
aria‑label .qc-lozenge Attribut recommandé. Indique la nature du statut au lecteur d'écran (ex : « Information », « Succès », « Erreur », « Avertissement », « Complément »). La couleur seule ne transmettant pas l'information aux utilisateurs de technologies d'assistance ou daltoniens.
qc‑general .qc-lozenge Pastille générale (bleue). Statut par défaut.
qc‑success .qc-lozenge Pastille de succès (verte).
qc‑error .qc-lozenge Pastille d'erreur (rouge).
qc‑warning .qc-lozenge Pastille d'avertissement (jaune).
qc‑complementary .qc-lozenge Pastille complémentaire (grise).
qc‑lozenge‑label <span> enfant Encapsule le libellé quand une icône est présente. Gère l'ellipse sur le texte.
qc‑lozenge‑group <div> conteneur Conteneur pour pastilles combinées. Gère l'espacement horizontal et vertical
